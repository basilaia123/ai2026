ლექცია 3: შეჯამება (API და No-Code ავტომატიზაცია)

📚 ლექციის მიზნები

  • API-ს (Application Programming Interface) მუშაობის პრინციპების გაგება.
  • Make.com-ში რთული ლოგიკური ოპერაციების (Routers, Iterators, Aggregators) აწყობა.
  • მონაცემების რეალურ დროში მიღება (Webhooks).
  • AI Coding Assistant-ების (Antigravity) და Advanced Web Scraping-ის გამოყენება.

1️⃣ Make.com Advanced

Iteration და Aggregation

მთავარი არსი: მასივებთან (Arrays) მუშაობა არის No-Code ავტომატიზაციის ყველაზე რთული, მაგრამ აუცილებელი ნაწილი.

  • Iterator (იტერატორი): იღებს ერთ დიდ სიას (მაგ. 5 ელფოსტა) და შლის ცალ-ცალკე მოქმედებებად. შესაბამისად, შემდგომი მოდული 5-ჯერ გაეშვება.
  • Aggregator (აგრეგატორი): შებრუნებული პროცესი. იღებს ბევრ ცალკეულ ინფორმაციას (მაგ. 5 გაანალიზებული ტექსტი) და აერთიანებს ერთ დიდ ტექსტად, რათა 1 ელფოსტით გააგზავნოს.

Data Routing (მონაცემთა მართვა)

Routers (მარშრუტიზატორები) და Filters (ფილტრები) არის IF-THEN პირობითი ლოგიკა. Router ანაწილებს ნაკადს 2 ან მეტ გზაზე, ხოლო ფილტრი ამოწმებს პირობას თითოეულ გზაზე (მაგ. "თუ თანხა მეტია $1000-ზე").

2️⃣ API და HTTP (ვების ენა)

როგორ საუბრობენ პროგრამები

API არის ოფიციალური "შემკვეთი", რომელიც იღებს თქვენს მოთხოვნას (მაგ. "რა ღირს ბიტკოინი?"), მიდის სერვერთან და უკან გიბრუნებთ პასუხს JSON ფორმატში.

  • GET მოთხოვნა: გამოიყენება ინფორმაციის წამოსაღებად (წასაკითხად).
  • POST მოთხოვნა: გამოიყენება ინფორმაციის გასაგზავნად (ახლის შესაქმნელად).
  • Headers: დამატებითი ინფორმაცია, სადაც ვათავსებთ ავტორიზაციის კოდებს (API Keys).

Webhooks (მომენტალური გამომწვევები)

თუ სტანდარტული API არის პერიოდული "შეკითხვა" (მაგ. ყოველ 15 წუთში ერთხელ ვამოწმებთ), Webhook არის პასიური მიმღები, რომელიც მუდამ უსმენს. როგორც კი გარე სისტემაში მოხდება რამე (მაგ. ახალი გადახდა), ის რეალურ დროში გვიგზავნის მონაცემებს.

3️⃣ AI Coding & Web Scraping

Google Antigravity & Firecrawl

ავტომატიზაციაში ხშირად ვაწყდებით რთულ მონაცემებს, რომლის დამუშავებაც No-Code მოდულებით რთულია (მაგ. რთული Regex წესები). ამ დროს ვიყენებთ Google Antigravity-ს, რათა მან დაგვიწეროს უნივერსალური კოდი (JavaScript/Python) რთული ინფორმაციის დასამუშავებლად.

ხოლო ვებ-გვერდებიდან ინფორმაციის ამოსაღებად (Lead Generation) ვიყენებთ Firecrawl-ს, რომელიც HTML-ს სუფთა Markdown-ად გარდაქმნის AI მოდელებისთვის.
