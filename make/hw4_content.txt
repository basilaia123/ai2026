🎯 დავალების მიზანი

ამ დავალების შესრულებით თქვენ:

გამოცდით Self-hosted ავტომატიზაციას და გაუშვებთ n8n-ს ლოკალურად.
ისწავლით Zero Data Leakage პრინციპების პრაქტიკაში გამოყენებას ლოკალური მოდელის (Ollama) მიერთებით.
ააწყობთ ციკლურ ლოგიკას (Looping) რთული კვლევითი ამოცანების ავტომატიზაციისთვის.



⚠️ ტექნიკური მოთხოვნები: ამ დავალებისთვის დაგჭირდებათ Docker Desktop-ის ინსტალაცია (და თუ Ollama-ს იყენებთ, კომპიუტერს უნდა ჰქონდეს მინიმუმ 8GB/16GB RAM). თუ თქვენი კომპიუტერი სუსტია, გააკეთეთ მხოლოდ ნაწილი 1 და ნაწილი 3 (ღრუბლოვანი AI-თ).
            


📋 დავალებები
შეასრულეთ ნაწილი 1 (სავალდებულო) და აირჩიეთ ერთ-ერთი არჩევითი (ნაწილი 2 ან 3) სრული 10 ქულის მისაღებად.



ნაწილი 1: n8n ლოკალური გაშვება (სავალდებულო) 🐳
5 ქულა


მოთხოვნა: დააყენეთ n8n თქვენს კომპიუტერზე Docker-ის გამოყენებით.

გადმოწერეთ და დააინსტალირეთ Docker Desktop (Windows/Mac).
გახსენით Terminal / Command Prompt და გაუშვით შემდეგი ბრძანება:
                            docker run -it --rm --name n8n -p 5678:5678 -v n8n_data:/home/node/.n8n docker.n8n.io/n8nio/n8n

ბრაუზერში შედით მისამართზე http://localhost:5678 და გაიარეთ რეგისტრაცია (ლოკალურად).
შექმენით ახალი Workflow და დაამატეთ 1 მარტივი Webhook Trigger-ი და Set ნოდი.






ნაწილი 2: Zero Data Leakage - Ollama-ს ინტეგრაცია (არჩევითი) 🔒
5 ქულა


მოთხოვნა: დააკავშირეთ ლოკალური n8n ლოკალურ AI მოდელთან უსაფრთხო გარემოს შესაქმნელად.

გადმოწერეთ Ollama და გაუშვით მოდელი ტერმინალიდან: ollama run llama3 ან qwen2.5 (დაელოდეთ ჩამოტვირთვას).
n8n-ში დაამატეთ **Basic LLM Chain** და **Ollama Chat Model** ნოდები.
დააკონფიგურირეთ Ollama-ს Base URL (ჩვეულებრივ http://host.docker.internal:11434).
გაუშვით ტესტი, სადაც n8n დაამუშავებს ტექსტს ლოკალური მოდელის დახმარებით, ინტერნეტის გარეშე.
