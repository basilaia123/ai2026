💻 1. უფასო ფინანსური მონაცემები: sources/markets.py

CoinGecko უფასო API კრიპტოვალუტებისთვის და Stooq უფასო CSV API ამერიკული აქციებისთვის (გასაღების გარეშე):

sources/markets.py (CoinGecko + Stooq CSV) 
import csv, io, os, requests

TIMEOUT = 10
HEADERS = {"User-Agent": "morning-briefing/1.0"}
CG_URL = "https://api.coingecko.com/api/v3/simple/price"
STOOQ_URL = "https://stooq.com/q/d/l/"

def fetch_crypto(ids: list[str], vs: str = "usd") -> list[dict]:
    """CoinGecko API: ფასი და 24 საათის ცვლილება (%)"""
    headers = dict(HEADERS)
    key = os.getenv("COINGECKO_API_KEY")  # არასავალდებულო Demo Key
    if key: headers["x-cg-demo-api-key"] = key
    r = requests.get(CG_URL, params={"ids": ",".join(ids), "vs_currencies": vs, "include_24hr_change": "true"}, headers=headers, timeout=TIMEOUT)
    r.raise_for_status()
    data = r.json()
    return [{"name": c, "price": data[c][vs], "change_pct": data[c].get(f"{vs}_24h_change")} for c in ids if c in data]

def fetch_stock(symbol: str) -> dict | None:
    """Stooq API: ბოლო ორი დღის Close ფასი და % ცვლილება (ფორმატი: aapl.us)"""
    r = requests.get(STOOQ_URL, params={"s": symbol, "i": "d"}, headers=HEADERS, timeout=TIMEOUT)
    r.raise_for_status()
    rows = [x for x in csv.DictReader(io.StringIO(r.text)) if x.get("Close")]
    if len(rows) < 2: return None
    last, prev = float(rows[-1]["Close"]), float(rows[-2]["Close"])
    return {"name": symbol.upper(), "price": last, "change_pct": (last - prev) / prev * 100}

⏰ 3. ყოველდღიური გაშვება: Windows Task Scheduler

PowerShell სკრიპტი, რომელიც აგენტს ავტომატურად უშვებს ყოველ სამუშაო დღეს 07:30 საათზე:

$action = New-ScheduledTaskAction `
  -Execute "C:\Users\GBASILAIA\claude\ai2026\morning-briefing\.venv\Scripts\python.exe" `
  -Argument "main.py" `
  -WorkingDirectory "C:\Users\GBASILAIA\claude\ai2026\morning-briefing"

$trigger = New-ScheduledTaskTrigger -Weekly -DaysOfWeek Monday,Tuesday,Wednesday,Thursday,Friday -At 7:30am

Register-ScheduledTask -TaskName "MorningBriefing" -Action $action -Trigger $trigger
