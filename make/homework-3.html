Make.com, API ინტეგრაცია და პირობითი ლოგიკა

სულ: 10 ქულა

⏱️ სავარაუდო დრო: 60-90 წუთი

🏠 მთავარი 📊 სლაიდები 📚 შეჯამება 💪 სავარჯიშოები ⚡ ცნობარი 📚 გზამკვლევი

🎯 დავალების მიზანი

ამ დავალების შესრულებით თქვენ:

  • გამოიყენებთ HTTP მოდულს Make.com-ში გარე API-სთან საკომუნიკაციოდ.
  • დაამუშავებთ JSON მონაცემებს და შექმნით ავტომატიზებულ სამუშაო პროცესს (Workflow).
  • გამოიყენებთ პირობით ლოგიკას (Filters ან Routers) რთული ავტომატიზაციის ასაწყობად.
⚠️ მნიშვნელოვანია: ეს დავალება მოითხოვს API დოკუმენტაციის წაკითხვას და JSON-ის სტრუქტურის გაგებას. გამოიყენეთ Google Antigravity ან ChatGPT ტექნიკური დახმარებისთვის!

📋 დავალებები

აირჩიეთ მხოლოდ ერთი სცენარი ქვემოთ ჩამოთვლილთაგან და ააწყვეთ სრული ავტომატიზაცია Make.com-ზე.

სცენარი 1: ვალუტის კურსის მონიტორი 💱 10 ქულა

რას აკეთებს: სცენარი იღებს ვალუტის კურსს API-დან, ამოწმებს პირობას და აგზავნის შეტყობინებას.

  • Trigger: Scheduler (გაეშვას მაგალითად, ყოველდღე 09:00).
  • API მოთხოვნა: გამოიყენეთ HTTP მოდული `https://api.exchangerate-api.com/v4/latest/USD` ან მსგავსი ღია API.
  • ლოგიკა: დაამატეთ **Router** ან **Filter**. მაგალითად: თუ 1 USD > 2.80 GEL, გაგზავნეთ შეტყობინება ერთი გზით, თუ არა - მეორე გზით (ან საერთოდ ნუ გააგზავნით).
  • Action: შედეგი გააგზავნეთ Telegram-ში, Slack-ში, ან Email-ზე.
სცენარი 2: ამინდის ავტომატური რეპორტი ☁️ 10 ქულა

რას აკეთებს: ამოწმებს ამინდს და აგენერირებს რჩევას AI-ს დახმარებით.

  • Trigger: Scheduler (მაგ: ყოველ დილით).
  • API მოთხოვნა: გამოიყენეთ HTTP მოდული OpenWeatherMap API-სთან (უფასო რეგისტრაცია).
  • AI ინტეგრაცია: მიღებული მონაცემები (ტემპერატურა, ნალექი) გადააწოდეთ OpenAI/Claude მოდულს რჩევის დასაწერად (მაგ: "გარეთ წვიმს, წაიღე ქოლგა").
  • Action: შეინახეთ მონაცემები Google Sheets-ში და/ან გააგზავნეთ მესენჯერში.
სცენარი 3: მოტივაციური ბოტი 💬 10 ქულა

რას აკეთებს: იღებს ციტატას, თარგმნის ქართულად და აქვეყნებს.

  • Trigger: Scheduler.
  • API მოთხოვნა: გამოიყენეთ HTTP მოდული `https://api.quotable.io/random` მისამართზე.
  • ფილტრი: გაატარეთ მხოლოდ ის ციტატები, რომლებიც 100 სიმბოლოზე ნაკლებია (Filter-ის გამოყენებით).
  • Action: თარგმნეთ AI-ს მეშვეობით და გააგზავნეთ არჩეულ არხზე (Slack/Telegram/Email).

API / HTTP ინტეგრაცია 4 ქულა HTTP მოდული სწორად არის დაკონფიგურირებული, JSON მონაცემები მოწოდებულია და სწორად არის დაპარსული.

სრული Workflow და ტესტი 3 ქულა სცენარი სრულად ფუნქციონირებს და მოწოდებულია წარმატებული გაშვების დამადასტურებელი ეკრანის ანაბეჭდი.
