📖 სასწავლო გზამკვლევი: ლექცია 2

როგორ გამოვიყენოთ ეს გზამკვლევი? ეს დოკუმენტი დაგეხმარებათ ლექციაზე მიღებული ცოდნის სტრუქტურირებაში და წარმოადგენს მთავარ თეორიულ სახელმძღვანელოს ფინალური პროექტისთვის მოსამზადებლად.

1. კონცეპტუალური ტრანზიცია (The Paradigm Shift)

ჩვენი კურსის მთავარი მიზანია Prompt Engineer-იდან გადავიქცეთ AI Automation Architect-ად. ამისთვის მნიშვნელოვანია გვესმოდეს შემდეგი ტერმინები:

ტერმინი განმარტება
Knowledge Base (ცოდნის ბაზა) თქვენი ბიზნესის სპეციფიკური დოკუმენტები, რომელსაც AI იყენებს სწორი კონტექსტის შესაქმნელად.
JSON (JavaScript Object Notation) მონაცემთა გაცვლის უნივერსალური ფორმატი. სისტემები (მაგ. n8n) ერთმანეთს ესაუბრებიან JSON ენით.
Embeddings ტექსტის, სურათის ან აუდიოს მათემატიკური (რიცხვითი) წარმოდგენა, რომელსაც AI კითხულობს.
Model Context Protocol (MCP) ახალი პროტოკოლი, რომელიც AI აგენტებს აძლევს ლოკალურ სერვერებზე წვდომის საშუალებას ფაილების Cloud-ში ატვირთვის გარეშე.

2. RAG სისტემის ანატომია

რა ხდება კულისებში, როცა AI-ს თქვენს დოკუმენტზე ეკითხებით?

1. თქვენ ატვირთავთ 100 გვერდიან PDF დოკუმენტს.

2. სისტემა ჭრის მას პატარა ნაწილებად (Chunks).

3. თითოეულ ნაწილს გარდაქმნის ვექტორად (Embeddings) და ინახავს ვექტორულ ბაზაში.

4. როცა სვამთ კითხვას, თქვენი კითხვაც გარდაიქმნება ვექტორად.

5. სისტემა ადარებს რიცხვებს და პოულობს ყველაზე რელევანტურ პასუხს (Semantic Search).

6. LLM კითხულობს ამ ამოღებულ ტექსტს და აგენერირებს ლამაზ, ადამიანურ პასუხს.

3. ReAct: როგორ ვაზროვნებინოთ აგენტს?

AI აგენტი არ არის უბრალოდ ჩატბოტი. ის არის სისტემა, რომელსაც შეუძლია შეასრულოს დავალება. ReAct (Reasoning + Acting) Framework-ის მიხედვით:

  • Reasoning: მიზნის გააზრება და დაგეგმვა. ("უნდა ვიპოვო კლიენტის ტელეფონის ნომერი").
  • Action: ხელსაწყოს გამოყენება. ("ვრთავ CRM API-ს").
  • Observation: შედეგის მიღება. ("CRM-მა დააბრუნა ნომერი").

ეს ციკლი გრძელდება მანამ, სანამ აგენტი არ მიაღწევს საბოლოო მიზანს.

4. Model Context Protocol (MCP) - ახალი ერა (2026)

MCP არის რევოლუციური. თუ ადრე გვიწევდა რთული OAuth და API დაკავშირება ყოველი სერვისისთვის, დღეს Claude Desktop App-ს შეუძლია პირდაპირ დაუკავშირდეს თქვენს კომპიუტერს.

  • MCP არ ტვირთავს თქვენს ლოკალურ ფაილებს Cloud-ში.
  • ის საშუალებას აძლევს Claude-ს "დაინახოს" თქვენი ლოკალური ფაილური სისტემა, მონაცემთა ბაზები და GitHub რეპოზიტორები.
  • ეს ხდის AI აგენტებს 100%-ით უსაფრთხოს Enterprise დონის კომპანიებისთვის (Zero-Leakage Policy).
