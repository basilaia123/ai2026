📋 სწრაფი ცნობარი (Cheat Sheet): ლექცია 2

🚨 Panic Button: რა ვქნა, თუ რამე გაფუჭდა? (10-Second Fixes)

  • ❌ Claude Project / GPTs ვერ პოულობს ფაილის ინფორმაციას (RAG Failure)? ➔ დოკუმენტის ტექსტი არ უნდა იყოს სკანირებული უბრალო სურათი (OCR გარეშე). ატვირთეთ სუფთა TXT, Markdown ან საძიებო PDF.
  • ❌ "MCP Server Connection Failed"? ➔ შეამოწმეთ JSON კონფიგურაციაში მძიმეები და ბილიკი (Path). ბილიკში გამოიყენეთ ორმაგი backslash (Windows: C:\\...) ან forward slash (/).
  • ❌ ReAct აგენტი გაიჭედა დაუსრულებელ ციკლში (Infinite Loop)? ➔ დაუწესეთ შეზღუდვა: "მაქსიმუმ 3 ხელსაწყოს გამოძახება (Max 3 tool iterations)".

⚡ 5-Minute Quick-Start: RAG ასისტენტი 3 ნაბიჯში

  • ☑️ 1. შექმენი პროექტი: Claude.ai ➔ Projects ➔ Create Project ("კომპანიის ასისტენტი").
  • ☑️ 2. ატვირთე ცოდნა: Project Knowledge-ში ჩააგდე PDF/Doc დოკუმენტი (ფაილის დამუშავება ავტომატურია).
  • ☑️ 3. ჩაურთე დამცავი წესი: Instructions-ში მიუთითე: "უპასუხე მხოლოდ ატვირთული ფაილიდან. თუ არ წერია, თქვი რომ არ იცი."

Assistant VS Agent (სწრაფი შედარება)

თვისება Assistant (ChatGPT/Claude) Agent (AutoGPT/Custom Agent)
ინიციატივა რეაქტიული (ელოდება თქვენს ბრძანებას) პროაქტიული (მოქმედებს მიზნისკენ)
Tools (ხელსაწყოები) შეზღუდული (მხოლოდ რაც აქვს ჩაშენებული) შეუძლია გარე API-ების და ლოკალური სერვისების ჩართვა
Workflows ერთი კითხვა - ერთი პასუხი მრავალეტაპიანი, დამოუკიდებელი დაგეგმვა

📝 JSON ფორმატის შაბლონი (ყველაზე მნიშვნელოვანი სტრუქტურა)

JSON (JavaScript Object Notation) არის გასაღები ნებისმიერი ავტომატიზაციის პლატფორმისთვის (Make.com, n8n).

{ "client": { "first_name": "გიორგი", "last_name": "მაისურაძე", "email": "giorgi@example.com" }, "request": "მჭირდება ფასდაკლება 20%", "status": "pending", "priority": 1 }

წესი 1: Keys (გასაღებები) ყოველთვის ბრჭყალებშია ("email").

წესი 2: ფიგურული ფრჩხილები {} ქმნიან ობიექტს.

🧠 ReAct Loop-ის 3 ოქროს წესი

  1. ყოველთვის მიეცით აგენტს მკაფიო პერსონა და მიზანი.
  2. აღუწერეთ ხელსაწყოები (Tools) ძალიან დეტალურად, რათა აგენტმა იცოდეს, როდის რომელი გამოიყენოს.
  3. დაუტოვეთ Fallback (ალტერნატიული გზა), თუ რომელიმე Action შეცდომით დასრულდა (Error Handling).

🔌 MCP (Model Context Protocol) ლოგიკა

MCP კავშირის დასამყარებლად საჭიროა 3 კომპონენტი:

  1. MCP Host: მაგალითად Claude Desktop აპლიკაცია, რომელიც ითხოვს ინფორმაციას.
  2. MCP Client: პროტოკოლი, რომელიც უზრუნველყოფს უსაფრთხო ლოკალურ კავშირს.
  3. MCP Server: ლოკალური პროგრამა (მაგ. ფაილური სისტემის წამკითხველი ან SQL ბაზა), რომელიც გასცემს მონაცემებს.
