💪 სავარჯიშოები: ლექცია 3 (API & No-Code)

✨ 100% Zero-Code გარანტია & 3-დონიანი სისტემა

ამ კურსზე პროგრამირების ცოდნა არ არის საჭირო! დავალებები დაყოფილია 3 დონედ:

  • 🥉 Bronze (5 წთ) [სავალდებულო]: მზა შაბლონის გაშვება 1 პარამეტრით. სერტიფიკატის ჩასათვლელად ეს სრულიად საკმარისია!
  • 🥈 Silver (15 წთ) [რეკომენდებული]: 1 დამატებითი ლოგიკური მოდულის მიბმა.
  • 🥇 Gold (Mastery) [არასავალდებულო]: ექსპერიმენტები მათთვის, ვისაც მეტი გამოწვევა სურს.

⚡ 5-Minute Quick-Start: Webhook 3 დაწკაპუნებით

  1. ნაბიჯი 1: Make.com ➔ Create a new scenario ➔ დაამატეთ Webhooks ➔ Custom webhook.
  2. ნაბიჯი 2: დააჭირეთ Add ➔ დაარქვით "QuickTest" ➔ დააკოპირეთ მოცემული URL ბუფერში (Copy address to clipboard).
  3. ნაბიჯი 3: გახსენით ბრაუზერის ახალი ჩანართი, ჩასვით URL, მიუწერეთ ბოლოში ?name=Giorgi და დააჭირეთ Enter. Make.com-ზე დაინახავთ მწვანე წარწერას: "Successfully determined"!

[🥉 Bronze - 5 წთ] დავალება 1: Webhook Trigger-ის აწყობა და გატესტვა

მიზანი: მიიღეთ მონაცემები რეალურ დროში კოდის დაუწერლად.

  1. Make.com-ში შექმენით ახალი სცენარი და დაამატეთ Webhooks -> Custom webhook პირველ (Trigger) მოდულად.
  2. დააკლიკეთ Add-ს და დაარქვით სახელი "My Test Webhook".
  3. დააკოპირეთ მოცემული URL (მაგ. https://hook.eu1.make.com/...).
  4. ბრაუზერის ახალ ფანჯარაში ჩასვით ეს URL და ბოლოში მიუწერეთ: ?name=Nino&role=Manager. დააჭირეთ Enter-ს (ბრაუზერი დაწერს "Accepted").
  5. დაბრუნდით Make.com-ში და დარწმუნდით, რომ მოდულმა წარმატებით დაიჭირა მონაცემები!

💡 მინიშნება: Webhook არის როგორც კარის ზარი. ბრაუზერში ლინკის გახსნა ნიშნავს ზარზე თითის დაჭერას - მონაცემები მომენტალურად ხვდება თქვენს სცენარში.

[🥈 Silver - 15 წთ] დავალება 2: HTTP მოდული და Public API

მიზანი: შექმენით სცენარი, რომელიც ინფორმაციას წამოიღებს გარე სერვერიდან და გამოგიგზავნით.

  1. Make.com-ში დაამატეთ HTTP -> Make a request მოდული.
  2. URL ველში ჩასვით უფასო Public API: https://api.chucknorris.io/jokes/random
  3. Method აირჩიეთ GET და Parse response მონიშნეთ Yes-ზე (რათა JSON ავტომატურად დაიშალოს).
  4. დააჭირეთ მარჯვენა ღილაკით მოდულს ➔ Run this module only.
  5. დაამატეთ მეორე მოდული: Email (Send an Email) ან Telegram/Slack და ტექსტის ველში ჩასვით წამოღებული value პარამეტრი.

💡 მინიშნება: Parse response = Yes ნიშნავს, რომ Make.com თავად გადათარგმნის JSON-ს მარტივ ველებად და კოდის წერა აღარ დაგჭირდებათ!

[🥇 Gold - Mastery] დავალება 3: Router და პირობითი ლოგიკა (Smart Traffic Light)

მიზანი: შემოსული მონაცემების მარშრუტიზაცია Router-ისა და Filter-ის გამოყენებით.

  1. დავალება 1-ში შექმნილი Webhook-ის შემდეგ მიაბით Router მოდული.
  2. გააკეთეთ ორი განშტოება (Flow A და Flow B).
  3. Flow A (VIP მარშრუტი): დააწკაპუნეთ წერტილოვან ხაზზე (Filter) ➔ Condition: role Equal to Manager. ამ გზაზე დაამატეთ შეტყობინება: "სასწრაფო: მენეჯერის მოთხოვნა!"
  4. Flow B (ჩვეულებრივი მარშრუტი): დააწკაპუნეთ ხაზზე ➔ ჩართეთ "The fallback route" = Yes (ყველა სხვა დანარჩენისთვის).
  5. დატესტეთ ბრაუზერიდან ერთხელ role=Manager-ით და მეორედ role=Guest-ით - დააკვირდით, როგორ ირჩევს Make.com სწორ გზას!
