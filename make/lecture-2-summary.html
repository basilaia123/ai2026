ლექცია 2: შეჯამება (Custom Assistants & Agents)

📚 ლექციის მიზნები

  • Custom GPTs და Claude Projects-ის გამოყენება.
  • ცოდნის ბაზების (Knowledge Bases) და RAG სისტემების გაგება.
  • ასისტენტებსა და AI აგენტებს შორის განსხვავების დანახვა (ReAct Framework).
  • Model Context Protocol (MCP) ტექნოლოგიის საფუძვლების შესწავლა.

1️⃣ ნაწილი 1: Custom Assistants & Knowledge Bases

Custom GPTs & Claude Projects

მთავარი არსი: უბრალო Chat ინტერფეისიდან გადავდივართ მორგებულ ასისტენტებზე. Claude Projects გვაძლევს საშუალებას ერთ სივრცეში მოვაქციოთ კონკრეტული პროექტის კონტექსტი, სისტემური ინსტრუქციები (Style & Tone) და დოკუმენტები (200K ტოკენამდე, რაც დაახლოებით 500 გვერდია).

RAG და ვექტორული ბაზები

  • RAG (Retrieval-Augmented Generation): AI-ის მიერ მოძიებული ინფორმაციის საფუძველზე პასუხის გენერაცია. (როგორც ბიბლიოთეკარი, რომელიც ჯერ წიგნს პოულობს და მერე გპასუხობთ).
  • Semantic Search (სემანტიკური ძიება): ინფორმაციის მოძიება შინაარსის და არა მხოლოდ ზუსტი სიტყვების მიხედვით. "ძაღლი" და "dog" აღიქმება ერთნაირად.
  • ვექტორული ბაზები (Vector DB): ტექსტი გარდაიქმნება რიცხვებად (Embeddings) და ინახება ისე, რომ AI-მ სწრაფად იპოვოს მსგავსი კონტექსტი.

2️⃣ ნაწილი 2: Autonomous Agents და ReAct Framework

Assistant VS Agent

ასისტენტი ელოდება თქვენს კითხვას, აგენტი კი - დამოუკიდებლად იღებს გადაწყვეტილებებს და იყენებს ინსტრუმენტებს (Tools) მიზნის მისაღწევად.

ReAct (Reasoning + Action)

აგენტის აზროვნების ციკლი შედგება 3 ნაბიჯისგან:

  1. Reasoning: აგენტი ფიქრობს რა უნდა გააკეთოს ("მჭირდება ინფორმაცია ამინდზე").
  2. Action: იყენებს კონკრეტულ Tool-ს ("ვრთავ API-ს").
  3. Observation: იღებს და აანალიზებს შედეგს ("წვიმს"). ამის მერე წყვეტს, დაასრულოს თუ ხელახლა იფიქროს.

3️⃣ ნაწილი 3: Model Context Protocol (MCP)

ახალი სტანდარტი სისტემების დასაკავშირებლად

ადრე, API-ების დასაკავშირებლად გვიწევდა რთული კოდის წერა ყოველი ახალი სერვისისთვის. MCP არის ახალი ღია სტანდარტი (შექმნილი Anthropic-ის მიერ), რომელიც საშუალებას აძლევს AI-ს პირდაპირ, უსაფრთხოდ დაუკავშირდეს თქვენს ლოკალურ ფაილებს, მონაცემთა ბაზებს და სერვისებს (Google Drive, Github, Slack).

მთავარი უპირატესობა: მონაცემები არსად არ იტვირთება (Zero-leakage). AI თავად მოდის მონაცემებთან.
