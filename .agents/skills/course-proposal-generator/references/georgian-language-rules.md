# ქართული ენის სტილისტური და გრამატიკული სტანდარტები (Georgian Style Guide)

შეთავაზებებისა და სილაბუსების ტექსტი მკაცრად უნდა შეესაბამებოდეს ამ წესებს (დაფუძნებულია `georgian-proofreader` სტანდარტზე):

---

## 1. პუნქტუაცია და სიმბოლოები (კრიტიკული წესები)

1. **დიდი და საშუალო ტირეების (Em-dash და En-dash) სრული აკრძალვა:**
   - ქართულ გრამატიკაში „—“ (em-dash) და „–“ (en-dash) არ გამოიყენება.
   - **აკრძალულია:** `პროგრამა — რეკომენდებული`, `10:00 – 12:00`.
   - **სწორია:** `პროგრამა - რეკომენდებული`, `10:00-12:00` (მარტივი სტანდარტული დეფისი `-`).

2. **ქართული ბრჭყალები ტექსტში:**
   - ხილულ ქართულ ტექსტში გამოიყენეთ მხოლოდ ორმაგი ქართული ბრჭყალები: `,,..."`.
   - *შენიშვნა:* არ შეცვალოთ სწორი ბრჭყალები (`"`, `'`) HTML ტეგების ატრიბუტებში, CSS კლასებში ან Markdown კოდის ბლოკებში.

3. **აბრევიატურების სრული გაშლა:**
   - ბიზნეს-შეთავაზებებში აკრძალულია შემოკლებები.
   - **არასწორი:** `მაგ.`, `სთ.`, `წთ.`, `გვ.`, `შპს`.
   - **სწორი:** `მაგალითად:`, `საათი`, `წუთი`, `გვერდი`, `შეზღუდული პასუხისმგებლობის საზოგადოება` (ან ოფიციალური დასახელება).

4. **პუნქტუაციის წინ სივრცის (Space) აკრძალვა:**
   - სასვენი ნიშნების ( . , ! ? : ; ) წინ არასდროს დასვათ ჰარარე (Space).

---

## 2. ხელოვნური ინტელექტის ტერმინოლოგია და ბრუნვები

1. **AI აკრონიმის ბრუნება:**
   - არ მიაბათ ქართული ბრუნვის ნიშნები პირდაპირ დეფისით (მოერიდეთ: `AI-ს`, `AI-ით`, `AI-ზე`).
   - **სწორი ფორმულირებები:**
     - „ხელოვნურ ინტელექტს“, „ხელოვნური ინტელექტით“, „ხელოვნურ ინტელექტზე“;
     - „AI მოდელს“, „AI ინსტრუმენტებით“, „AI სისტემაში“.

2. **ინგლისური ტექნიკური ტერმინების შენარჩუნება:**
   - არ თარგმნოთ დამკვიდრებული ტექნიკური და ბიზნეს ტერმინები:
     - `Prompt`, `Prompt Engineering`, `Workflow`, `ROI`, `BoQ`, `API`, `Zero-shot`, `Few-shot`, `Chain-of-Thought`, `Action Items`, `Meeting Minutes`, `Pitch Deck`, `Visual Aid`, `SOP`.

3. **კორპორატიული ბარბარიზმების ჩანაცვლება:**
   - `თასქი` ➔ `დავალება`
   - `დეფოლტად` ➔ `ნაგულისხმევად`
   - `ქეისი` ➔ `შემთხვევა` ან `ბიზნეს-მაგალითი`
   - `აზრი აქვს` ➔ `მიზანშეწონილია` / `გონივრულია`

4. **ციფრული მამრავლები:**
   - `10x` ➔ `10-ჯერ`
   - `2-3x` ➔ `2-3-ჯერ`

---

## 3. ტონი და რეგისტრაცია (Tone of Voice)

- შეთავაზება უნდა იყოს **პროფესიული, საქმიანი (Formal Business Executive)**, თუმცა მკაფიო და უსტრესო.
- გამოიყენეთ ზრდილობიანი ფორმა: **„თქვენ“** (არა „შენ“).
- ხაზი გაუსვით რეალურ შედეგებს, დროის ეკონომიასა და პრაქტიკულ უნარებს (Hands-On), მშრალი აკადემიური თეორიის გარეშე.
