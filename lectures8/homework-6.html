⚡ საშინაო დავალება #6

სამუშაო პროცესების ავტომატიზაცია და AI აგენტები

No-Code ავტომატიზაცია Make.com-ზე: Webhooks, OpenAI/Claude მოდული, Telegram/Sheets ინტეგრაცია და ROI

⏰ ვადა: 1 კვირა ლექციის შემდეგ
📊 ქულა: 7 ქულა (საშინაო დავალებების 50-ქულიანი ბადისთვის)
⏱️ სავარაუდო დრო: ~35-45 წუთი
🛠️ ინსტრუმენტები: Make.com, OpenAI / Claude Module, Webhook, Google Sheets ან Telegram Bot

🎯 დავალების მიზანი

ამ დავალებაში თქვენ შექმნით ავტონომიურ სამუშაო პროცესს (AI Workflow) პლატფორმა Make.com-ზე. სისტემამ უნდა შეძლოს შემოსული ინფორმაციის ავტომატური მიღება (Trigger), მისი გაანალიზება AI მოდელით (OpenAI/Anthropic), და შედეგის რეალურ დროში გაგზავნა ან ბაზაში შენახვა (Action). ასევე გაიანგარიშებთ მიღებულ ეკონომიკურ ეფექტს (ROI და დაზოგილი სამუშაო საათები).

[Trigger: Google Sheets / Form / Webhook] ↓ (JSON მონაცემები) [AI Module: OpenAI GPT-4o / Claude 3.5 Sonnet] ↓ (სტრუქტურირებული პასუხი / კლასიფიკაცია) [Action: Telegram Bot შეტყობინება / Gmail / CRM]
Make.com Custom Webhooks OpenAI Create Chat Completion Google Sheets Telegram Bot API Model Context Protocol (MCP)

📋 დავალების ნაწილები

  • ნაწილი 1: Make.com სცენარის არქიტექტურა და აწყობა 3.0 ქულა ⏱️ 15-20 წთ

    ამოცანა: Make.com-ზე ააწყვეთ მინიმუმ 3-მოდულიანი სამუშაო სცენარი რეალური ბიზნეს-ამოცანისთვის:

    1. Trigger (ტრიგერი):
      • ვარიანტი A: Google Sheets - Watch New Rows (ახალი შეკვეთა ან მომხმარებლის მოთხოვნა);
      • ვარიანტი B: Custom Webhook (მონაცემების მიღება გარე ფორმიდან ან ვებსაიტიდან);
      • ვარიანტი C: Gmail / Telegram - Watch Incoming Messages;
    2. AI დამუშავება (AI Module):
      • OpenAI (Create a Completion / Chat Completion) ან Anthropic Claude მოდული;
      • გაწერილი მკაფიო System Prompt (მაგ. მოთხოვნის სენტიმენტის დადგენა, ენის ამოცნობა, ავტომატური პასუხის მონახაზი, ან მონაცემთა ექსტრაქცია);
      • წინა მოდულიდან გადმოცემული ველების სწორი Mapping;
    3. Action (ქმედება):
      • Telegram - Send a Text Message (ადმინისტრატორის ან ჯგუფის მყისიერი შეტყობინება);
      • ან Gmail - Send an Email (მომხმარებლისთვის პასუხის გაგზავნა);
      • ან Google Sheets - Update Row (ცხრილის შევსება AI დასკვნით).

  • ნაწილი 2: სცენარის ტესტირება და გაშვების ლოგები (Execution Proof) 2.0 ქულა ⏱️ 10-12 წთ

    ამოცანა: დაადასტურეთ, რომ სცენარი გამართულად მუშაობს რეალური სატესტო მონაცემებით:

    1. გაუშვით სცენარი (ღილაკი „Run once“);
    2. გადაეცით სატესტო მონაცემი (მაგ. ჩაწერეთ ახალი სტრიქონი Google Sheets-ში ან გააგზავნეთ Webhook payload);
    3. დარწმუნდით, რომ სამივე მოდულზე გაჩნდა მწვანე ინდიკატორი (Success);
    4. გახსენით AI მოდულის Input / Output ბუშტი და გადაუღეთ სქრინშოტი (დარწმუნდით, რომ AI-მ სწორად დაამუშავა მოთხოვნა);
    5. გადაუღეთ სქრინშოტი მიღებულ საბოლოო შეტყობინებას (Telegram/Gmail/Sheets).

  • ნაწილი 3: ROI (დაზოგილი რესურსების) ანალიზი და MCP პერსპექტივა 2.0 ქულა ⏱️ 10-12 წთ

    ამოცანა: შეაფასეთ შექმნილი ავტომატიზაციის ბიზნეს-ღირებულება და სამომავლო განვითარება:

    დოკუმენტში უპასუხეთ შემდეგ კითხვებს:

    • ხელით შესრულების დრო: რამდენ წუთს ანდომებდა თანამშრომელი ამ პროცესს თითო ოპერაციაზე? (მაგ. 8 წუთი);
    • Make.com-ის სიჩქარე: რამდენი წამი დასჭირდა ავტომატიზაციას? (მაგ. 3.2 წამი);
    • ROI გაანგარიშება: თვეში 100 მსგავსი მოთხოვნის შემთხვევაში, რამდენი საათი და თანხა ($) ეზოგება კომპანიას/თქვენ?
    • MCP & AI Agents პერსპექტივა (2-3 წინადადება): როგორ შეიძლება ამ სცენარის გაუმჯობესება Model Context Protocol (MCP) სტანდარტით ან ავტონომიური აგენტით (მაგ. რომ აგენტმა თავად გადაწყვიტოს, როდის ჩართოს სხვა ხელსაწყო).

📊 შეფასების რუბრიკა

კომპონენტი ქულა კრიტერიუმები
Make.com სცენარის აგებულება 3.0 ქულა ლოგიკური არქიტექტურა (Trigger → AI Module → Action), სწორი მონაცემთა mapping და გამართული System Prompt
ტესტირება და Execution Proof 2.0 ქულა წარმატებული Run-ის სქრინშოტი, Input/Output ლოგები და საბოლოო მიღებული შედეგის (შეტყობინების) დემონსტრირება
ROI ანალიზი და MCP პერსპექტივა 2.0 ქულა დაზოგილი დროისა და თანხის რეალისტური გათვლა, აგენტური გაფართოების ლოგიკური ხედვა
სულ 7.0 ქულა სრულად მომუშავე AI ავტომატიზაცია
