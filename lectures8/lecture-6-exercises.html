სავარჯიშო 1 · დამწყები

🔗 პირველი სცენარი: Google Sheets → OpenAI → Telegram Bot

მიზანი: შექმენით ავტომატური ნაკადი, რომელიც ახალ შემოსულ შეკითხვას გააანალიზებს AI-ით და ადმინისტრატორს გაუგზავნის შეტყობინებას.

  1. შექმენით ახალი Google Sheet სვეტებით: ID, Customer_Name, Inquiry_Text, Status;
  2. Make.com-ზე დაამატეთ ტრიგერი: Google Sheets → Watch New Rows;
  3. დაამატეთ მოდული: OpenAI → Create a Completion / Chat Completion;
    System Prompt: „განსაზღვრე მოთხოვნის კატეგორია (ტექნიკური/ფინანსური/ზოგადი) და სენტიმენტი (პოზიტიური/ნეგატიური/ნეიტრალური)“;
  4. დაამატეთ მოქმედება: Telegram Bot → Send a Text Message და გაგზავნეთ შეჯამებული ანალიზი თქვენს Telegram ჩათში;
  5. დააჭირეთ „Run once“, ჩაწერეთ სატესტო სტრიქონი ცხრილში და დარწმუნდით, რომ სამივე მოდული გამწვანდა.
სავარჯიშო 2 · საშუალო

🔀 Router და ჭკვიანი ფილტრები (Smart Routing)

მიზანი: შექმენით მრავალგანშტოებიანი ლოგიკა მომხმარებლის ემოციური მდგომარეობის მიხედვით.

  1. წინა სცენარში OpenAI მოდულის შემდეგ ჩასვით Router;
  2. განშტოება A (ნეგატიური/კრიტიკული): ფილტრი: Sentiment = Negative → გააგზავნეთ გადაუდებელი ალერტი Slack/Telegram-ში ტეგით 🚨 URGENT: უკმაყოფილო კლიენტი;
  3. განშტოება B (სტანდარტული): ფილტრი: Sentiment != Negative → ჩაწერეთ Google Sheets-ის მეორე გვერდზე "Processed Inquiries";
  4. გატესტეთ ორივე სცენარი ორი განსხვავებული ტექსტით.
სავარჯიშო 3 · მოწინავე

🤖 Make 2026 "Run an Agent" მოდულის ტესტირება Chat Sandbox-ში

მიზანი: დაეუფლეთ ჰექსაგონალურ აგენტურ მოდულს ცოდნის ბაზით (Knowledge RAG).

  1. სცენარში აირჩიეთ მოდული "Run an Agent";
  2. Brain: მიუთითეთ Claude 3.5 Sonnet ან GPT-4o, განსაზღვრეთ კომპანიის ოფიციალური კონსულტანტის როლი;
  3. Knowledge: ატვირთეთ სატესტო PDF ან FAQ ტექსტი (მაგ. კომპანიის ფასების პრეისკურანტი);
  4. გახსენით Chat Sandbox პირდაპირ Make-ის ტილოზე და დაუსვით 3 განსხვავებული შეკითხვა;
  5. გადაამოწმეთ Glass-Box Reasoning View — როგორ იპოვა აგენტმა პასუხი ატვირთულ დოკუმენტში.
სავარჯიშო 4 · ეკონომიკური ანალიზი

📈 ROI და დროის დაზოგვის კალკულაცია

მიზანი: გამოთვალეთ თქვენი აწყობილი ავტომატიზაციის რეალური ბიზნეს-ღირებულება.

შეავსეთ ქვემოთ მოცემული მეტრიკები თქვენი სცენარისთვის:

  • ხელით შესრულების დრო: რამდენ წუთს მოითხოვდა ეს პროცესი ხელით? (მაგ. 6 წუთი);
  • Make-ის შესრულების სიჩქარე: რამდენ წამში დაასრულა მოდულმა? (მაგ. 4 წამი);
  • თვიური მოცულობა: თვეში 150 მსგავსი მოთხოვნისას, რამდენი საათი გამოთავისუფლდა? (150 × 6 / 60 = 15 საათი);
  • თვიური ფინანსური დანაზოგი: 15 სთ × $20/სთ = $300 თვეში.
