🌟 რა არის Google Antigravity 2.0?

Google Antigravity 2.0 არის Google DeepMind-ის მიერ შექმნილი სრულიად ახალი თაობის AI-First Autonomous Agentic Development Platform. თუ წინა თაობის რედაქტორები მხოლოდ კოდის ფრაგმენტებს გიკარნახებდნენ (Code Autocomplete), Antigravity 2.0 წარმოადგენს სრულფასოვან ავტონომიურ წყვილ-პროგრამისტს (Pair Programmer).

მას შეუძლია დამოუკიდებლად დაგეგმოს კომპლექსური საინჟინრო ამოცანა, შექმნას და გაუშვას სპეციალიზებული ქვეაგენტები (Subagents), შეასრულოს ტერმინალის ბრძანებები უსაფრთხო სენდბოქსში, გამოიყენოს Model Context Protocol (MCP) გარე ბაზებთან დასაკავშირებლად და წარმოადგინოს ცოცხალი, ინტერაქტიული არტეფაქტები.

🤖

ავტონომიური წყვილ-პროგრამისტი

ასრულებს მრავალეტაპიან დავალებებს ადამიანის მუდმივი ზედამხედველობის გარეშე, კითხულობს და არედაქტირებს კოდბაზას.

👥

Subagents (ქვეაგენტების გუნდი)

რთულ დავალებას ყოფს და უშვებს პარალელურ ქვეაგენტებს (მაგ: მკვლევარი, ტესტერი, დეველოპერი) იზოლირებულ Workspace-ში.

🔌

MCP 2026 ეკოსისტემა

Anthropic Model Context Protocol-ის სრული ინტეგრაცია: პირდაპირი წვდომა GitHub-ზე, ბაზებზე, API-ებსა და ხელსაწყოებზე.

🛡️

ტერმინალის სენდბოქსი

მკაცრი უსაფრთხოების წესები: სისტემური ბრძანებების იზოლირებული გაშვება და უფლებების კონფიგურირებადი პოლიტიკა.

🖥️ Antigravity-ის 3 ძირითადი ინტერფეისი (Surfaces)

Google Antigravity წარმოდგენილია 3 ურთიერთშემავსებელ გარემოში თქვენი სამუშაო სტილის შესაბამისად:

A

Antigravity 2.0 Desktop Application (Electron)

ცალკე მდგომი მძლავრი დესკტოპ აპლიკაცია, რომელიც დამოუკიდებლად უშვებს და ორკესტრირებს აგენტებს თქვენს კომპიუტერზე:

  • Left Sidebar: ახალი საუბარი (New Conversation), პროექტები (Projects/Workspaces), დაგეგმილი ფონური ამოცანები (Scheduled Tasks • Cron), Skills & MCP მართვა;
  • Chat Canvas: მთავარი სამუშაო პანელი Slash ბრძანებებით (/), @-Mentions (ფაილები, წესები, MCP სერვერები) და სურათების/დოკუმენტების ატვირთვით;
  • Auxiliary Panes: ქვეაგენტების მონიტორინგი (Subagents), ფონური ტასკები (Background Tasks), არტეფაქტები (Artifacts) და შეცვლილი ფაილების დიფი (Files Changed).
B

Antigravity IDE (AI-First VS Code Fork)

პროფესიონალური კოდის რედაქტორი ჩაშენებული აგენტური სამუშაო ნაკადებით:

  • Antigravity Tab (Autocomplete & Supercomplete): შემდეგი ნაბიჯის პროგნოზი 1 კლავიშით (Tab to Jump, Tab to Import, Supercomplete მრავალხაზიანი ცვლილებებისთვის);
  • Inline Command (Ctrl+I / Cmd+I): მონიშნული კოდის ლოკალური რეფაქტორინგი, ახსნა ან ახალი კოდის ჩასმა;
  • Sidebar Chat & Agent Mode: მრავალეტაპიანი ავტონომიური რეჟიმი, სადაც აგენტი კითხულობს ფაილებს, უშვებს ტერმინალს, ტესტავს და ასწორებს შეცდომებს;
  • Inline Code Lenses: ღილაკები ფუნქციების თავზე ("Refactor", "Write Tests", "Explain Code").
C

Antigravity CLI (agy)

მსუბუქი ტერმინალური ინტერფეისი ბრძანებათა სტრიქონიდან სწრაფი მუშაობისთვის. იდეალურია headless სერვერებზე, ავტომატურ CI/CD მილსადენებსა და დეველოპერებისთვის, რომლებსაც ტერმინალიდან გაუსვლელად სურთ აგენტის გამოძახება.

🧠 ქვეაგენტების (Subagents) არქიტექტურა

Antigravity 2.0-ის ერთ-ერთი ყველაზე მძლავრი ინოვაციაა ქვეაგენტების დელეგირების სისტემა. როდესაც მთავარი აგენტი რთულ პრობლემას აწყდება, ის არ ცდილობს ყველაფრის ერთ კონტექსტში გაკეთებას, არამედ ააქტიურებს სპეციალიზებულ ქვეაგენტებს:

🔍

Research Subagent

მხოლოდ კითხვის რეჟიმში მომუშავე აგენტი, რომელიც სწრაფად იკვლევს კოდბაზას, ეძებს ფაილებს და აკეთებს ვებ-ანალიტიკას.

🧪

Testing Subagent

ატარებს ტესტებს, აგროვებს ლოგებს და ამოწმებს, ხომ არ გატყდა სისტემა ბოლო ცვლილებების შემდეგ.

🎨

Image & UI Subagent

ქმნის ვიზუალურ კომპონენტებს, გრაფიკებს, დიაგრამებსა და ინტერაქტიულ არტეფაქტებს.

🔧

Custom Defined Subagent

მომხმარებელს ან მთავარ აგენტს შეუძლია რეალურ დროში განსაზღვროს ახალი ტიპის ქვეაგენტი საკუთარი სისტემური ინსტრუქციით.

Workspace რეჟიმები ქვეაგენტებისთვის:

  • inherit: ქვეაგენტი მუშაობს იმავე სამუშაო საქაღალდეში, სადაც მთავარი აგენტი;
  • branch: ქვეაგენტისთვის იქმნება იზოლირებული სამუშაო გარემო (Git Branch-ის მსგავსად), სადაც ის ექსპერიმენტებს ატარებს მთავარი კოდის დაუზიანებლად;
  • share: გაზიარებული რეპოზიტორია დუბლირების გარეშე (Git Worktree-ის ანალოგი).

⚡ Slash ბრძანებები და სამუშაო ნაკადები

Antigravity 2.0-ში ჩაშენებულია სპეციალური Slash ბრძანებები რთული საინჟინრო პროცესების ავტომატიზაციისთვის:

ბრძანება დანიშნულება როდის გამოვიყენოთ?
/plan ეტაპობრივი საინჟინრო დაგეგმვა სანამ აგენტი კოდის წერას დაიწყებს, ქმნის დეტალურ გეგმას მომხმარებლის დასადასტურებლად.
/grill-me ინტერაქტიული დიზაინ-ინტერვიუ აგენტი გისვამთ კითხვებს არქიტექტურაზე, რათა ზუსტად გაიგოს მოთხოვნები.
/goal გრძელვადიანი ავტონომიური რეჟიმი აგენტი მუშაობს უწყვეტად მიზნის სრულ მიღწევამდე (მაგ: ღამით კომპლექსური რეფაქტორინგი).
/browser ვებ-ბრაუზერის ავტომატიზაცია ბრაუზერის მართვა, ვებ-აპლიკაციის ტესტირება, კლიკები და სკრინშოტების ანალიზი.
/compact კონტექსტის შეკუმშვა საუბრის ისტორიის შეჯამება კონტექსტური ფანჯრის გასათავისუფლებლად.
/schedule ფონური ტასკები და ტაიმერები პერიოდული (Cron) ან გადადებული დავალებების ჩანიშვნა ფონურ რეჟიმში.

🛡️ უსაფრთხოება, ნებართვები და ტერმინალის სენდბოქსი

Google Antigravity 2.0 შექმნილია უსაფრთხოების უმაღლესი სტანდარტებით კორპორატიული და პირადი მონაცემების დასაცავად:

🔒

Terminal Sandbox

აგენტის მიერ გაშვებული ბრძანებები შეიძლება შესრულდეს იზოლირებულ სენდბოქსში, სადაც სისტემურ ფაილებზე წვდომა შეზღუდულია.

📜

Tool Execution Policy

პოლიტიკის არჩევა: always-proceed (ავტომატური), request-review (დასტურით), ან strict.

📂

Workspace File Access

პროექტის საქაღალდის გარეთ ფაილების წაკითხვის/ჩაწერის მკაცრი კონტროლი (allow, ask, deny).

🌐

Domain & URL Allowlist

შეზღუდვა ინტერნეტში: აგენტს შეუძლია ეწვიოს მხოლოდ წინასწარ დამტკიცებულ ვებ-დომენებს.

💡 როდის რომელი გამოვიყენოთ?

გამოიყენეთ Cursor AI, როდესაც გსურთ აქტიურად, ხელით წეროთ კოდი და გჭირდებათ უსწრაფესი Tab Autocomplete და მრავალფაილიანი Composer რედაქტორი.
გამოიყენეთ Google Antigravity 2.0, როდესაც გაქვთ კომპლექსური, მრავალეტაპიანი საინჟინრო პროექტი, რომელიც მოითხოვს ავტონომიურ კვლევას, ქვეაგენტების გაშვებას, ტესტების ჩატარებას და ფონურ ავტომატიზაციას.
