## 🧠 ძირითადი თემები და კონცეფციები

### 1. Intent-First Software Development
ტრადიციულ პროგრამირებაში შემქმნელი ფიქრობს სინტაქსზე, კლასებზე, მეხსიერებაზე და ბიბლიოთეკების დამოკიდებულებებზე. AI-Native No-Code-ში აქცენტი გადადის:
- პროდუქტის მოთხოვნების მკაფიო ფორმულირებაზე;
- მონაცემთა ობიექტებისა და მათი კავშირების განსაზღვრაზე;
- მომხმარებლის ინტერფეისის (UX) ეტაპების ლოგიკაზე.

### 2. Lovable 2.0 არქიტექტურა
- **React + Vite + Tailwind CSS:** ინდუსტრიული სტანდარტის სუფთა კოდი.
- **Chat vs Dev Mode:** სწრაფი გლობალური ცვლილებები ჩატში ან მიზნობრივი შესწორებები ვიზუალური ინსპექტორით.
- **GitHub Sync:** პროექტის სრული კოდის ექსპორტი რეპოზიტორიაში.
- **Cloud Hosting:** მყისიერი HTTPS ლინკი მეგობრებთან და კლიენტებთან გასაზიარებლად.

### 3. Supabase Backend
- **Postgres Database:** ცხრილები, პირველადი გასაღებები (`UUID`), Foreign Keys.
- **Row Level Security (RLS):** უსაფრთხოების ფუნდამენტური ფენა, რომელიც კრძალავს უცხო მომხმარებლის ჩანაწერების წაკითხვას ან შეცვლას.
- **Auth Provider:** მზა ლოგინი, რეგისტრაცია და სესიების მართვა.

### 4. Google AI Studio & Gemini 2.0 Flash
- **Multimodal Vision & Audio:** კამერის კადრის, ატვირთული ფოტოს ან ხმის პირდაპირი ანალიზი.
- **Structured JSON Schema:** გარანტია, რომ API დააბრუნებს მკაცრად ვალიდურ JSON-ს, რომლის დამუშავებაც Android (Kotlin)-ში მარტივია (GSON / Kotlinx.serialization).
- **Get Code:** ერთი კლიკით კოდის გადატანა Android Studio-ში.

### 5. AI-First IDEs: Cursor & Google Antigravity
- **Cursor:** VS Code-ის მოდერნიზებული ჩანგალი (Composer `Cmd+I`, Smart Autocomplete, `@Codebase` ინდექსაცია).
- **Google Antigravity:** ავტონომიური სამუშაო გარემო, სადაც პარალელური აგენტები (Subagents) ასრულებენ კომპლექსურ კვლევით და კოდირების ამოცანებს.
