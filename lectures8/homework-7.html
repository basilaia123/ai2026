📱 საშინაო დავალება #7

No-Code აპლიკაციების შექმნა და Android დეველოპმენტი

Lovable 2.0 Web App (Supabase-ით) ან Android აპლიკაციის პროტოტიპი Google AI Studio-ში (Gemini 2.0)

⏰ ვადა: 1 კვირა ლექციის შემდეგ
📊 ქულა: 6 ქულა (საშინაო დავალებების 42-ქულიანი ბადისთვის, 7 × 6 ქულა)
⏱️ სავარაუდო დრო: ~35-50 წუთი
🛠️ ინსტრუმენტები: Lovable.dev (ვარიანტი A) ან Google AI Studio (ვარიანტი B) + Cursor/Antigravity Showcase

🎯 დავალების მიზანი

ამ დავალებაში თქვენ შექმნით ფუნქციურ ინტერაქტიულ აპლიკაციას. თქვენ გაქვთ შესაძლებლობა აირჩიოთ თქვენი ინტერესებისთვის შესაბამისი გზა:

ვარიანტი A: Web / No-Code

Lovable 2.0 Web App

სრული Full-Stack ვებ-აპლიკაცია ბუნებრივი ენით (Lovable.dev), მონაცემთა ბაზით (Supabase ან LocalStorage) და საჯარო Deploy ლინკით.

ვარიანტი B: Mobile / Android

Google AI Studio + Android

Android აპლიკაციის პროტოტიპი Google AI Studio-ში: Gemini 2.0 Flash, Structured JSON Schema და მზა Kotlin/Jetpack Compose კოდის ექსპორტი.

Lovable.dev Supabase Google AI Studio Gemini 2.0 Flash Structured Output (JSON) Android (Kotlin) Cursor & Antigravity Demo

📋 დავალების ნაწილები (აირჩიეთ A ან B)

  • ნაწილი 1: აპლიკაციის კონცეფცია და პრომპტირება 2.0 ქულა ⏱️ 12-15 წთ

    ამოცანა: შეარჩიეთ 1 კონკრეტული იდეა და მოამზადეთ საწყისი სისტემური მითითება (Prompt):

    იდეის მაგალითები:

    • AI Fitness Coach: მომხმარებელი უთითებს წონას/მიზანს და იღებს პერსონალურ ვარჯიშის გეგმას;
    • Smart Expense Tracker: ხარჯების აღრიცხვა, კატეგორიზაცია და ვიზუალური დიაგრამები;
    • Client Intake / Booking: სერვისზე ჩაწერის ფორმა დროის შერჩევითა და ავტომატური დადასტურებით;
    • Recipe Generator: მაცივარში არსებული ინგრედიენტებით კერძის რეცეპტების გენერირება.

    მოთხოვნა: დაწერეთ დეტალური Prompt, სადაც განსაზღვრავთ: აპლიკაციის სახელს, მიზანს, ფერთა პალიტრას (Tailwind სტილი), ძირითად ღილაკებსა და ველებს.

  • ნაწილი 2: ფუნქციონალის აწყობა და მონაცემთა მოდელი 2.0 ქულა ⏱️ 15-20 წთ

    განახორციელეთ შერჩეული ვარიანტის მიხედვით:

    🌐 თუ აირჩიეთ ვარიანტი A (Lovable 2.0):

    1. გახსენით lovable.dev და ჩასვით თქვენი პირველადი Prompt;
    2. დაამატეთ მონაცემების შენახვის ლოგიკა (მაგ. ჩანაწერის დამატება, წაშლა, ძებნა/დაფილტვრა);
    3. იტერაციულად ჩაასწორეთ მინიმუმ 2 დეტალი ჩატში (მაგ. „შეცვალე ღილაკების ფერი“, „დაამატე Export to CSV“);
    4. ჩართეთ Supabase ინტეგრაცია (ან გამოიყენეთ LocalStorage state).

    📱 თუ აირჩიეთ ვარიანტი B (Google AI Studio & Android):

    1. გახსენით aistudio.google.com და აირჩიეთ მოდელი Gemini 2.0 Flash;
    2. System Instructions: გაუწერეთ AI-ს როლი თქვენი Android აპლიკაციისთვის;
    3. Structured Output: ჩართეთ Structured Output და განსაზღვრეთ JSON Schema (მაგ. { title: string, priority: string, steps: string[], estimatedMinutes: number });
    4. დატესტეთ რამდენიმე შეყვანილ მონაცემზე და დარწმუნდით, რომ მოდელი აბრუნებს მკაცრად ვალიდურ JSON-ს;
    5. დააჭირეთ „Get Code“ ღილაკს და შეარჩიეთ Kotlin (ან REST API / cURL) Android აპლიკაციაში ჩასაშენებლად.

  • ნაწილი 3: ლაივ დემო / კოდის ექსპორტი და IDE რეფლექსია 2.0 ქულა ⏱️ 10-12 წთ

    ამოცანა: წარმოადგინეთ შედეგი და უპასუხეთ მოკლე ანალიტიკურ შეკითხვას:

    1. შედეგის ფიქსაცია:
      • ვარიანტი A: Lovable-ში დააჭირეთ Publish და წარმოადგინეთ ცოცხალი საჯარო ბმული + 2-3 სქრინშოტი;
      • ვარიანტი B: Google AI Studio-ს პრომპტის/JSON სქემის სქრინშოტი და "Get Code"-ით გენერირებული Kotlin კოდის ფრაგმენტი;
    2. AI-First IDE რეფლექსია (3-4 წინადადება):

      ლექციაზე ნაჩვენები Cursor AI-სა და Google Antigravity-ის დემოზე დაყრდნობით, როგორ ცვლის AI-Native გარემოები ტრადიციული დეველოპმენტის სიჩქარეს და რატომ არის მნიშვნელოვანი არაპროგრამისტებისთვის ამ ინსტრუმენტების გააზრება?
