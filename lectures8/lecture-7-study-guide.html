ლექცია 7 - სასწავლო გზამკვლევი

📱 No-Code ვებ-დეველოპმენტი და Android აპლიკაციები

Lovable 2.0, Supabase, Google AI Studio Android Prototyping & AI-First IDEs

🎯 1. სწავლის მიზნები

🌐 Web No-Code

  • Lovable 2.0-ით Full-Stack აპლიკაციის აწყობა
  • Tailwind UI-ის და კომპონენტების იტერაციული კონტროლი
  • Supabase ბაზის, RLS-ისა და ავთენტიფიკაციის გამართვა
  • 1-Click Cloud Deployment და GitHub სინქრონიზაცია

📱 Mobile & AI Tools

  • Google AI Studio & Gemini 2.0 Flash შესაძლებლობები
  • Structured Output (JSON Schema) გარანტირებული პასუხებისთვის
  • Android (Kotlin) კოდის ექსპორტი და კამერის/Vision ინტეგრაცია
  • Cursor AI და Google Antigravity-ის აგენტური სამუშაო გარემო

📋 2. წინასწარი მომზადების ჩექლისტი

  • Lovable.dev: შექმენით უფასო ანგარიში;
  • Supabase.com: შექმენით უფასო პროექტი Postgres ბაზისთვის;
  • Google AI Studio: დარწმუნდით, რომ გაქვთ წვდომა aistudio.google.com-ზე და შექმენით API Key;
  • იდეის ჩამოყალიბება: შეარჩიეთ 1 კონკრეტული სერვისი (მაგ. Booking, Expense Tracker, ან Receipt Scanner).

🧠 3. საკვანძო ცნებები

⚡ Intent-First Development

პროგრამირების ახალი ერა, სადაც ადამიანი განსაზღვრავს ბიზნეს-მოთხოვნებსა და ლოგიკას, ხოლო AI წერს კოდსა და აკავშირებს კომპონენტებს.

🗄️ Row Level Security (RLS)

Supabase-ის უსაფრთხოების მექანიზმი, რომელიც ბაზის დონეზე უზრუნველყოფს, რომ მომხმარებელმა ნახოს მხოლოდ საკუთარი ჩანაწერები.

📐 Structured JSON Schema

Google AI Studio-ს პარამეტრი, რომელიც ზღუდავს Gemini-ს თავისუფალ ტექსტს და აბრუნებს მკაცრად განსაზღვრულ JSON მონაცემებს.

💻 Composer & Agentic IDE

Cursor-ისა და Antigravity-ის ინოვაციური რეჟიმები, სადაც AI-ს შეუძლია ერთდროულად რამდენიმე ფაილის რედაქტირება და დამოუკიდებელი დავალებების შესრულება.

❓ 4. თვითშემოწმების კითხვები

  1. რა განსხვავებაა ჩვეულებრივ Landing Page-სა და Full-Stack ვებ-აპლიკაციას შორის? რატომ არის Supabase აუცილებელი მეორესთვის?
  2. რატომ არ შეიძლება service_role_key-ის ჩაწერა Frontend კოდში?
  3. როგორ ეხმარება Structured Output-ი Android დეველოპერს Gemini API-ის ინტეგრაციაში?
  4. რა უპირატესობა აქვს Cursor AI-ის Composer რეჟიმს ტრადიციულ Copy-Paste მიდგომასთან შედარებით?

📝 5. საშინაო დავალება #7 (8.0 ქულა)

აირჩიეთ ერთ-ერთი მიმართულება:

  • ვარიანტი A (Web / No-Code): Lovable 2.0-ით აწყობილი Full-Stack ვებ-აპლიკაცია (მონაცემთა შენახვითა და საჯარო Deploy ლინკით).
  • ვარიანტი B (Mobile / Android): Google AI Studio-ში Gemini 2.0 Flash-ით აწყობილი Android პროტოტიპი (Structured JSON Schema და Kotlin ექსპორტი).

ორივე შემთხვევაში წარმოადგინეთ მოკლე რეფლექსია Cursor AI-სა და Google Antigravity-ის დემოზე დაყრდნობით.
