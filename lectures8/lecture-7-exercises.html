🌐 Lovable 2.0: Full-Stack აპლიკაციის შექმნა და 1-კლიკით Deploy

მიზანი: შექმენით მომუშავე ვებ-აპლიკაცია Lovable-ში ბუნებრივი ენით, დაუკავშირეთ მონაცემთა ბაზა (LocalStorage ან Supabase) და გაუშვით საჯარო ლინკზე.

ნაბიჯი 1: საწყისი არქიტექტურული პრომპტი

შედით lovable.dev-ზე და გამოიყენეთ სტრუქტურირებული საწყისი მითითება:

"შექმენი თანამედროვე 'Client Booking & Service Portal' მცირე ბიზნესისთვის (მაგ. სტომატოლოგიური კლინიკა ან ავტოსერვისი). მოთხოვნები: 1. მთავარი გვერდი: სერვისების კატალოგი ფასებით და ხანგრძლივობით; 2. Booking Form: მომხმარებელი ირჩევს სერვისს, თარიღს/საათს, შეჰყავს სახელი და ტელეფონი; 3. Confirmation View: წარმატებული ჯავშნის ბარათი უნიკალური კოდით; 4. Admin Dashboard: ადმინისტრატორის ჩანართი, სადაც ჩანს ყველა ჯავშანი სტატუსებით (Pending, Confirmed, Completed); 5. სტილი: სუფთა Tailwind UI, ლურჯი (#2563eb) აქცენტებით, მობაილზე ადაპტირებული."

ნაბიჯი 2: იტერაციული დახვეწა Chat & Dev Mode-ში

აპლიკაციის პირველადი გენერაციის შემდეგ შეასრულეთ მინიმუმ 2 იტერაცია:

  • იტერაცია 1: „დაამატე ძებნის ველი და ფილტრი ადმინ პანელში ჯავშნის სტატუსის მიხედვით.“
  • იტერაცია 2: „დაამატე ღილაკი 'Export to CSV', რომელიც ჩამოტვირთავს ჯავშნების სიას ცხრილად.“

ნაბიჯი 3: Deployment და შემოწმება

  • დააჭირეთ Publish ღილაკს ზედა მარჯვენა კუთხეში;
  • გახსენით გენერირებული ლინკი მობილურ ტელეფონში და შეამოწმეთ შეყვანილი მონაცემების შენახვა;
  • შეინახეთ ცოცხალი საჯარო ლინკი.
💡 რჩევა: თუ გსურთ რეალური მონაცემთა ბაზა, დაკლიკეთ „Connect Supabase“ და Lovable ავტომატურად გაუშვებს საჭირო SQL მიგრაციებს.
სავარჯიშო 2 · ვორქშოფი

📱 Google AI Studio: Android აპლიკაციის პროტოტიპი (Gemini 2.0 Flash)

მიზანი: Google AI Studio-ში Gemini 2.0 Flash-ის მომზადება Android მობილური აპლიკაციისთვის Structured JSON Output-ითა და Kotlin კოდის ექსპორტით.

ნაბიჯი 1: გარემოს გამართვა

  • გახსენით aistudio.google.com;
  • აირჩიეთ მოდელი: Gemini 2.0 Flash;
  • System Instructions ველში გაუწერეთ:
    "შენ ხარ Android აპლიკაციის ჭკვიანი ასისტენტი. შენი ამოცანაა მომხმარებლის მიერ ატვირთული ფოტოს/ტექსტის ანალიზი. პასუხი ყოველთვის უნდა იყოს მკაცრად ვალიდური JSON, markdown ფორმატირების გარეშე."

ნაბიჯი 2: Structured Output (JSON Schema) კონფიგურაცია

პარამეტრების პანელში ჩართეთ Structured Output და ჩასვით შემდეგი სქემა:

{ "type": "object", "properties": { "itemName": { "type": "string" }, "category": { "type": "string" }, "detectedPrice": { "type": "number" }, "confidenceScore": { "type": "number" }, "suggestedAction": { "type": "string" } }, "required": ["itemName", "category", "detectedPrice"] }

ნაბიჯი 3: ტესტირება და კოდის ექსპორტი

  • შეიყვანეთ ტესტური ტექსტი ან ატვირთეთ ნებისმიერი ჩეკის/ნივთის სურათი;
  • დარწმუნდით, რომ მოდელი აბრუნებს სუფთა JSON ობიექტს;
  • დააჭირეთ Get Code და შეარჩიეთ Kotlin Android Studio-ში ინტეგრაციისთვის.
