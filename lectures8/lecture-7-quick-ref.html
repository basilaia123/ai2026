🗄️ 3. Supabase ინტეგრაციის ჩექლისტი

🔗 1. დაკავშირება

  • შექმენით პროექტი supabase.com-ზე
  • Project Settings > API-დან დააკოპირეთ:
  • SUPABASE_URL
  • SUPABASE_ANON_KEY (საჯარო)
  • Lovable-ში დაკლიკეთ Connect Supabase

🔒 2. უსაფრთხოება & RLS

  • ჩართეთ Row Level Security (RLS) ყველა ტაბულაზე
  • პოლიტიკა: auth.uid() = user_id
  • მომხმარებელი ვერ ნახავს სხვის მონაცემებს
  • არასოდეს გამოიყენოთ service_role კლიენტის კოდში!
-- Supabase SQL Schema Example create table habits ( id uuid default gen_random_uuid() primary key, user_id uuid references auth.users not null, title text not null, streak integer default 0, created_at timestamp with time zone default timezone('utc'::text, now()) not null ); alter table habits enable row level security; create policy "Users can view own habits" on habits for select using (auth.uid() = user_id); create policy "Users can insert own habits" on habits for insert with check (auth.uid() = user_id);

🤖 4. Google AI Studio & Structured JSON Output

Android აპლიკაციებთან ინტეგრაციისთვის ყველაზე საიმედო მეთოდია Structured Output (JSON Schema) ჩართვა Gemini 2.0 Flash-ში:

⚙️ პარამეტრები Studio-ში

  • Model: Gemini 2.0 Flash (სწრაფი & იაფი)
  • System Instructions: მკაფიო როლი & შეზღუდვები

📱 5. Android (Kotlin) Gemini API Snippet

Google AI Studio-ს "Get Code" ღილაკით გენერირებული Kotlin კოდის სტრუქტურა Android აპლიკაციაში გამოსაყენებლად:

// build.gradle.kts: implementation("com.google.ai.client.generativeai:generativeai:0.9.0") import com.google.ai.client.generativeai.GenerativeModel import com.google.ai.client.generativeai.type.content val generativeModel = GenerativeModel( modelName = "gemini-2.0-flash", apiKey = BuildConfig.GEMINI_API_KEY ) // Multimodal Call: Bitmap სურათის გაგზავნა კამერიდან suspend fun analyzeReceipt(bitmap: Bitmap): String { val response = generativeModel.generateContent( content { image(bitmap) text("ამოიცანი ჩეკის მონაცემები და დააბრუნე Structured JSON.") } ) return response.text ?: "" }
