ლექცია 6 — გაკვეთილის გეგმა

აუდიო, ხმა და ვიდეო გენერაცია: მოდელის შერჩევიდან 30-წამიან კამპანიამდე

ხანგრძლივობა: 2.5 საათი სლაიდები: 37 აქტუალობა: 2026-09-22 ფორმატი: დემო + პრაქტიკა

სასწავლო შედეგები

სტუდენტი შეძლებს

  • მუსიკისთვის შეადაროს Suno v6, Lyria 3 Pro და Eleven Music 2.5;
  • განასხვაოს expressive narration და low-latency voice agent;
  • ვიდეო მოდელი აირჩიოს ხარისხის, native audio-ს, კონტროლის, ფასისა და კონფიდენციალურობის მიხედვით;
  • დაწეროს კინემატოგრაფიული prompt და შექმნას მოკლე კამპანიის workflow;
  • გადაამოწმოს კომერციული პირობები, თანხმობა, provenance და წყლის ნიშნები.

ინსტრუმენტური რუკა

  • მუსიკა: Suno v6, Lyria 3 Pro, Eleven Music 2.5;
  • ხმა: Eleven v3, Flash v2.5, Cartesia Sonic-3.6, OpenAI Realtime;
  • ვიდეო: Krea Realtime 14B, Decart Lucy 2.5, StreamDiffusionV2, Wan 3.0, Gemini Omni Flash, MiniMax H3, Runway, Veo/Flow, Kling;
  • ავატარი/რედაქტირება: HeyGen, Hedra, Descript, Opus Clip.

ლექციამდე მომზადება

  • ☐ გახსენით მთავარი სლაიდები და გადაამოწმეთ დემო ბმულები.
  • ☐ მოამზადეთ ერთი ქართული ტექსტი narration-ისა და realtime voice-ის შესადარებლად.
  • ☐ მოამზადეთ ერთი image reference და ერთი საერთო video prompt 2–3 მოდელში გამოსაცდელად.
  • ☐ გადაამოწმეთ ფასები, free-tier ლიმიტები და ხელმისაწვდომობა ოფიციალურ გვერდებზე.
  • ☐ იქონიეთ წინასწარ გენერირებული შედეგები, თუ live generation დაგვიანდება.
უსაფრთხოების წესი: კლასში არ გამოიყენოთ სხვისი ხმა ან სახე მკაფიო თანხმობის გარეშე.

დემონსტრირების სცენარი

1 — მუსიკა

ერთი ბრიფი გაუშვით ორ მოდელში. შეადარეთ ვოკალი, სტრუქტურა, prompt adherence, რედაქტირება და პირობები.

2 — ხმა

Eleven v3-ში შექმენით expressive narration; Flash ან Sonic-3.6 გამოიყენეთ სწრაფი agent response-ისთვის.

3 — ვიდეო

ჯერ შეადარეთ live streaming და offline clip generation. შემდეგ ერთი prompt და reference გამოსცადეთ 2–3 მოდელში; შეაფასეთ first-frame latency, FPS, მოძრაობა, კონსისტენტურობა, ხმა და ღირებულება.

4 — გამოქვეყნება

აჩვენეთ სუბტიტრი, 9:16 safe zones და repurposing; შეაფასეთ watch time, completion, saves და shares.

Live Challenge — 30-წამიანი ვიდეო

  1. ბრიფი: აირჩიეთ პროდუქტი, სერვისი ან საგანმანათლებლო იდეა.
  2. სცენარი: დაწერეთ hook, სამი მთავარი კადრი და CTA.
  3. ხმა: განსაზღვრეთ narrator, ტონი, ენა და თანხმობის წყარო.
  4. მუსიკა: აღწერეთ ჟანრი, განწყობა, BPM და კომერციული გამოყენების მოთხოვნა.
  5. ვიდეო: შეარჩიეთ მოდელი და დაასაბუთეთ არჩევანი ოთხი კრიტერიუმით.
  6. QA: შეამოწმეთ ფაქტები, ანატომია, ტექსტი, ხმა, provenance და ფორმატი.
შედეგი: ჯგუფი აბარებს ერთგვერდიან production plan-ს ან მოკლე პროტოტიპს.
