რა არის ვაიბ კოდინგი (Vibe Coding) და როგორ მუშაობს Lovable.dev?

✦

ტრადიციული ვებ დეველოპმენტი vs 2026 წლის Vibe Coding

წარსულში ივენთ-დიზაინერი ხატავდა Figma-ში, გადასცემდა დეველოპერს, ელოდებოდა კვირეებს, ასწორებდა შეცდომებს და იხდიდა ათასობით დოლარს. Vibe Coding არის ახალი პარადიგმა: დიზაინერი საუბრობს ბუნებრივი ენით (ქართულად ან ინგლისურად), აღწერს ესთეტიკასა და ქცევას, ხოლო AI (Lovable, Bolt, Cursor) რეალურ დროში აგენერირებს production-grade კოდს (React, Tailwind CSS, Vite).

ძველი პროცესი (3-4 კვირა)
  • Figma ესკიზი -> Frontend დეველოპერი -> Backend დეველოპერი;
  • სერვერის ყიდვა, ბაზის გამართვა, რთული ავთენტიფიკაცია;
  • მცირე ტექსტის შესაცვლელად დეველოპერის ჩართვა;
  • ხარჯი: 3,000$ - 7,000$ თითოეულ ივენთ-საიტზე.
Vibe Coding (15-30 წუთი)
  • დიზაინერი პირდაპირ პრომპტით ქმნის და ცვლის ინტერფეისს;
  • Google Sheets გამოიყენება როგორც უფასო, ცოცხალი მონაცემთა ბაზა;
  • მყისიერი 1-Click Publish ინტერნეტში მორგებული დომენით;
  • ხარჯი: 0$ (ინსტრუმენტის სტანდარტული გამოწერის ფარგლებში).

function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = {};
    
    // Parse JSON payload or URL-encoded form data
    if (e.postData && e.postData.contents) {
      try {
        data = JSON.parse(e.postData.contents);
      } catch (err) {
        data = e.parameter;
      }
    } else {
      data = e.parameter || {};
    }

    var timestamp = new Date().toISOString();
    var guestId = 'VN-' + Math.floor(100000 + Math.random() * 900000);
    var fullName = data.fullName || data.name || 'Anonymous Guest';
    var phone = data.phone || '';
    var email = data.email || '';
    var status = data.status || 'Attending';
    var plusOne = data.plusOne ? 'Yes (' + (data.plusOneName || 'Guest') + ')' : 'No';
    var dietary = data.dietary || 'None';
    var tableNo = data.tableNo || 'TBD';
    var qrCodeUrl = 'https://api.qrserver.com/v1/create-qr-code/?size=250x250&data=' + encodeURIComponent(guestId + '|' + fullName);

    // Append row to Google Sheet
    sheet.appendRow([
      timestamp,
      guestId,
      fullName,
      phone,
      email,
      status,
      plusOne,
      dietary,
      tableNo,
      qrCodeUrl
    ]);

    var result = {
      success: true,
      message: 'RSVP confirmed successfully',
      guestId: guestId,
      fullName: fullName,
      qrCodeUrl: qrCodeUrl
    };

    return ContentService
      .createTextOutput(JSON.stringify(result))
      .setMimeType(ContentService.MimeType.JSON);

  } catch (error) {
    var errorResult = {
      success: false,
      error: error.toString()
    };
    return ContentService
      .createTextOutput(JSON.stringify(errorResult))
      .setMimeType(ContentService.MimeType.JSON);
  }
}

function doGet(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var rows = sheet.getDataRange().getValues();
  var totalGuests = Math.max(0, rows.length - 1);
  
  var result = {
    status: 'online',
    event: 'Vanilla Events VIP Gala',
    totalConfirmed: totalGuests
  };

  return ContentService
    .createTextOutput(JSON.stringify(result))
    .setMimeType(ContentService.MimeType.JSON);
}

Quality Assurance
01. CORS შეცდომა (Network Error on Form Submit)

გამოსავალი: Apps Script-ზე მოთხოვნის გაგზავნისას Fetch-ში გამოიყენეთ mode: 'no-cors' ან გადაამოწმეთ, რომ Web App დეპლოიზე მონიშნულია Who has access: Anyone.

02. გვერდის გადატვირთვა ფორმის გაგზავნისას (Page Reload)

გამოსავალი: ყოველთვის ჩაამატეთ e.preventDefault() form submit ივენთზე, რათა მომხმარებლის მიერ შეყვანილი მონაცემები არ წაიშალოს.

03. ჰორიზონტალური გადახვევა მობილურზე (Horizontal Overflow)

გამოსავალი: არ გამოიყენოთ ფიქსირებული პიქსელური სიგანეები (მაგ. w-[1200px]). გამოიყენეთ max-w-7xl w-full mx-auto px-4 და overflow-x-hidden.

04. დაუცველი საიდუმლო გასაღებები (Hardcoded API Keys)

გამოსავალი: არასდროს ჩაწეროთ OpenAI ან Resend პირადი API გასაღებები კლიენტის React კოდში. გამოიყენეთ Apps Script ან Lovable backend secrets.
